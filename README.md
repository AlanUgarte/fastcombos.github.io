# FastCombos — Cotillón Tyna

Página única de catálogo de cotillón (`index.html`), con todos los artículos de la
categoría "Cotillon" del listado de precios de Tyna, precio +40% sobre el bruto
de bulto. Carrito, buscador, y pedido por WhatsApp (`remito.html` genera el
comprobante). Los datos de productos viven en el array `PRODUCTS.cotillon` dentro
de `index.html`; para actualizarlos, volvé a exportar el listado de precios de
Tyna y regenerá ese array.
